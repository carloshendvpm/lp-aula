StreamFlix — Landing Page em Camadas

Este mini-projeto foi criado para uma miniaula sobre desenvolvimento de uma landing page responsiva com HTML, CSS e JavaScript. A ideia é começar mostrando a versão pronta e depois voltar nas etapas de construção.

1. Mostrar primeiro: versão completa HTML + CSS + JavaScript funcionando. 2. Depois: apenas HTML A página existe, mas ainda está crua visualmente. 3. Depois: HTML + CSS A página fica bonita e responsiva, mas sem interação real. 4. Final: HTML + CSS + JS Adicionamos comportamento ao formulário.
