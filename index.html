Material de aula

Construindo uma landing page em etapas

Esta página reúne as versões usadas na aula da StreamFlix, uma landing page fictícia criada para estudar estrutura HTML, estilização com CSS, responsividade e interações simples com JavaScript.

Como usar este material

Primeiro veja a versão completa para entender o resultado final. Em seguida, abra cada etapa e compare o que muda quando adicionamos marcação, estilos e comportamento.

1. Versão completa Veja a experiência final com layout responsivo, menu mobile e validação do formulário. 2. Etapa HTML Observe a estrutura sem estilos: cabeçalho, seções, formulário, cards e perguntas frequentes. 3. Etapa HTML + CSS Compare como cores, espaçamentos, grid e media queries transformam a apresentação. 4. Etapa HTML + CSS + JS Analise o JavaScript responsável pelo menu, pela validação do e-mail e pelas mensagens na tela.
