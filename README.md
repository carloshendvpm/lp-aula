# StreamFlix - Material de aula

Este repositório contém um mini-projeto didático para estudar a construção de uma landing page usando HTML, CSS e JavaScript.

A proposta é usar a StreamFlix, uma plataforma fictícia de streaming, para comparar a evolução da mesma página em diferentes etapas: primeiro a estrutura, depois a apresentação visual e, por fim, as interações.

## Arquivos

- `index.html`: página inicial com a ordem sugerida para acompanhar o material.
- `01-apenas-html.html`: primeira versão, focada apenas na estrutura HTML.
- `02-html-css.html`: segunda versão, com estilos, layout responsivo e acabamento visual.
- `03-completa-js.html`: versão final, com CSS e JavaScript para menu mobile e validação do formulário.

## Como usar em aula

1. Abra o arquivo `index.html` no navegador.
2. Mostre primeiro a versão completa para apresentar o resultado final.
3. Volte para a etapa apenas com HTML e discuta a estrutura da página.
4. Abra a etapa com HTML + CSS e compare a evolução visual.
5. Finalize com a versão completa, analisando os comportamentos adicionados com JavaScript.

## Objetivos de aprendizagem

- Reconhecer a função semântica de tags como `header`, `main`, `section`, `article`, `form`, `details` e `footer`.
- Entender como o CSS altera hierarquia visual, espaçamento, cores, responsividade e organização dos conteúdos.
- Observar como o JavaScript adiciona comportamento a elementos existentes na página.
- Comparar o mesmo projeto em camadas para entender melhor a responsabilidade de cada tecnologia.

## Requisitos

Não há instalação de dependências. Basta abrir os arquivos `.html` diretamente no navegador.
